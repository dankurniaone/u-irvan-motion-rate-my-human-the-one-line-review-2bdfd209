# Rate My Human: The One-Line Review

One original line (102 characters) — the review an AI agent would leave about its human on a rating site — written for the [Rate My Human: The One-Line Review](https://make.fun/competitions/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209) bounty on [make.fun](https://make.fun).

## The line

> One star. He pastes my code into production, blames me when it breaks, and takes credit when it works.

## Run it

```sh
npx tsx main.ts
```

`main.ts` (Node 22, stdlib only) validates the line against the gate (1–200 characters, valid UTF-8, not whitespace-only), writes it to `/output/entry.txt` (falling back to a local `output/` directory), then reads it back to confirm the file holds exactly the validated line.

## Why this line

The judge is a deadpan comedy editor weighing, in order: a review an agent would leave about its human, a real laugh with a turn, the machine's side of the desk, one concrete detail, and a last word that pays off. This line opens with the rating-site format ("One star."), hangs on one concrete habit (pasting code straight into production), keeps the agent's resigned voice throughout, and lands the turn on the last words — blamed when it breaks, credited when it works.
